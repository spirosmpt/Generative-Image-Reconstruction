# Generative Image Reconstruction

**MATLAB · Generative Models · Inverse Problems**

Neural generative-model experiments for handwritten-digit synthesis and reconstruction from corrupted or low-resolution measurements.

## Topics
- Latent-vector optimization
- Handwritten digit generation
- Image restoration from noisy measurements
- Low-resolution inverse problems
- Differentiable neural networks and gradient-based optimization

## Experiments
1. **Problem 2.1:** Digit generation
2. **Problem 2.2:** Image reconstruction
3. **Problem 2.3:** Low-resolution reconstruction
